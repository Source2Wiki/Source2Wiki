The improvements from Source 1 to Source 2 drastically changed how a map is structured. Even with the Valve's Import Tool, considerable amount of work is needed to make the map fully operational and up to the same quality as in CS:GO.

It is important to fully implement information presented in this section into the port. This ensures that the port is stable in the live server gameplay, and less likely for servers to reject the port due to quality issues.
