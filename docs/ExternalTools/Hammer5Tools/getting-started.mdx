This guide installs <Tool name="hammer5tools"/> for <Game name="cs2"/> Workshop Tools and introduces the main application window. It requires 64-bit Windows 10 or 11 and an installed copy of the Workshop Tools.

## Installation

Download the latest release from the <Tool name="hammer5tools" label="Hammer 5 Tools website"/>, run the installer, and start <Tool name="hammer5tools"/> from the Start menu.

:::warning[Windows Defender]
The installer is not code-signed, so Windows may show a reputation or antivirus warning.
Download it only from the official site.
:::

## Main window

The addon selector sets the addon used by every editor and utility. Save open files before switching addons.

The launch button says Edit map when the configured command opens a map; otherwise it
says Launch Tools. Use the adjacent addon menu to create, import, export, delete, or
open an addon and to edit launch parameters.

The Git button opens the active addon's sync workflow. Map Builder opens the map build
queue. The Utilities menu opens SourcePorter, UnrealPorter, NavMesh Radar,
Cleanup Content, and Cleanup _vrad3 cache.

Closing the window sends it to the notification area when Minimize on Close is
enabled. Open Settings to change that setting.

## About and updates

The About window shows the installed version and links to documentation, guides,
feedback, and community support. Use Don't show on startup to hide it when
<Tool name="hammer5tools"/> opens.

The Updater shows the installed and available versions. Click ReleaseNotes to
read the changes. Click Update to install the offered release.
