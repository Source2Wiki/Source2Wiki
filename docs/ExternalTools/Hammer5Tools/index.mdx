<Tool name="hammer5tools"/> is a desktop toolset for <Game name="cs2"/> Workshop projects. It includes editors for SmartProps, sound events, audio, detail props, hotkeys, and loading screens, alongside build, cleanup, source-porting, and asset-management utilities.

These pages document <Tool name="hammer5tools"/> 6.0.1, verified against source commit
`df84c414c252455dd935ee7dad89de8979b154d9`.
Download the current build from the <Tool name="hammer5tools" label="Hammer 5 Tools website"/>.

:::note[Documentation baseline]
Labels and behavior can change in development builds. These pages use the stable 6.0.1
interface unless a page explicitly says otherwise.
:::

Community SmartProps and VSmart examples are maintained in the external <Tool name="hammer5tools" label="VSmart Library" link="https://hammer5tools.github.io/vsmart-library.html"/>.
