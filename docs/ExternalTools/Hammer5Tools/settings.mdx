Open Settings from the application interface to change stored preferences.

## General

Click Open UserData to open <Tool name="hammer5tools"/> settings and user files. Click Open Console to show the application console.

Set <Game name="cs2"/> path when the game installation is not detected. Set Archive path for stored exports and archives.

Select System, Dark, Bright, or Vintage Steam under Theme. Enable Minimize on Close to send the main window to the notification area when it is closed.

Enable Receive dev versions to use the development update channel. Click Cleanup model browser cache after assets were removed or thumbnails stopped matching their files.

Use the file-association buttons to assign `.vsmart`, `.vsndevts`, and `.hbat` files to
<Tool name="hammer5tools"/>.

## Git sync

Generate commit messages fills the Git message field from the selected changes.

## SmartProp Editor

Display ID with variable class changes variable labels after the file is reopened.
Hide experimental properties and elements hides unverified schema items from the
menus used to add them. Items already stored in a file are kept.

Under VMAP Importing, enable Round values during VMAP import and set Decimal places to control imported numeric values.

Set Anti-aliasing for the 3D viewport. Reopen the file after changing it.

## AssetGroupMaker

Use Folders to monitor to choose folders available to Watch the changes. Restart <Tool name="hammer5tools"/> after changing the list.

## SoundEventEditor

Enable Play on Click to play an audio file when it is selected in the Sound Explorer.

Use the Settings dialog to change these values.
