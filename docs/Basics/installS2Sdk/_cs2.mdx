1. Launch <Game name="cs2" /> from **Steam**.  
2. Click on the **Settings menu**. 
3. Search for **Install Counter-Strike Workshop Tools**.
4. Change the setting to **Yes**.

![Cs2 settings menu button](./pic/cs2/cs2Settings1.png "Settings Menu")  
![Cs2 settings search buttom](./pic/cs2/cs2Settings2.png "Settings Search")  
![Cs2 settings workshop search](./pic/cs2/cs2Settings3.png "Settings Search Workshop")  
![Cs2 settings "Install Counter-Strike Workshop Tools" button](./pic/cs2/cs2Settings4.png "Settings Install Tools")  

After this quit out of the game, and wait for the workshop tools to install.
